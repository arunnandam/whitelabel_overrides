Hiding the Tabs in Thoughtspot can only be done by their Tab ID.

This is sample code in the embed variable that I have done for 'Infiniti Dashboard'

```
liveboardId: "2b3c3696-030f-41be-8d83-f24b3da765a2",
     hideIrrelevantChipsInLiveboardTabs: true,
     isLiveboardCompactHeaderEnabled: true,

     visibleTabs: ['5af3e78e-b4df-4dd3-8768-4ea6f180281d',
     '16c0a805-32ed-417f-8d23-b65aa248e348'],
```

This example will show the two tabs in the Infiniti Liveboard.

Note: We can find the Tab ID in the Liveboard URL.
